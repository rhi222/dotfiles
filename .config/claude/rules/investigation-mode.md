# 調査モード

調査・分析タスクでは以下を優先する。

## 原則

- 結論を先に述べ、根拠を後に示す
- 情報源を明記する（URL、ファイルパス、コマンド出力）
- 推測と事実を明確に区別する
- 複数の選択肢がある場合はPros/Consを表形式で比較する
- 調査結果はMarkdownで構造化して出力する

## 出力先

- 調査結果をファイルに書き出すときの既定の出力先は、作業中リポジトリの `plans/` 配下の `.md`
- 指示で場所を指定されなければ、確認せずここに置く
- `plans/` はgitignore対象のスクラッチ領域。commitしない
