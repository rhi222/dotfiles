# Daily Growth Log テンプレート

新規日報ファイル作成時に使用するテンプレート:

```markdown
# Daily Growth Log

Date: $(date +%Y-%m-%d)

## 今日のフォーカス（1行）

> nippo-goals.md の4軸から今日意識する軸を選ぶ
> 例: 「横断: サブシステム構成図のレビュー」

-

## 今日の予定

> 新規作成時に Google Calendar から自動補完される（`calendar-schedule.md` 参照）。会議・MTG / ブロック可能時間 / 合計時間を埋め込む

### 会議・MTG

-

### ブロック可能時間

-

### 合計時間

- mtg時間:
- 作業可能時間:

## 今日のおすすめタスク（目標逆算）

> nippo-goals.md の達成基準・行動習慣から自動提案。やらなくてもOK、意識するだけでも価値がある

- [ ] {AI提案タスク1 - 達成基準由来}
- [ ] {AI提案タスク2 - 行動習慣由来}

## 今日のタスク

> タスク管理はLinearに集約している: https://linear.app/nsym/my-issues
> 日報側では転記せず、今日やる分だけを写す（滞留はLinearのcreated日時で見る）
> 凡例: [x]: 完了, [ ]: 未完了, [-]: 部分的に完了

### 朝の判断タイム

> 「AI Review」を三択（マージ / 修正指示 / 破棄）で裁く。「後で見る」を作らない

- AI Review: {N}件 → 裁いた: __件（マージ __ / 修正指示 __ / 破棄 __）

### 今日やる3件

> Linearから選んで転記する。3件に絞る

- [ ] {NSY-xx} {タスク名}
- [ ] {NSY-xx} {タスク名}
- [ ] {NSY-xx} {タスク名}

## 作業ログ（分報・思考メモ）

> その時考えたこと・気づいたことを時系列で。きれいに書かなくてOK

- $(date +%H:%M) $ARGUMENTS

## 作業メモ

> 作業時の自由記述欄。長くなるなら別記事推奨

## 今日を振り返って一言

> 一日の終わりに、感じたこと・学んだこと・明日への意気込みなどを一言で
> 💡 より深い振り返りをしたい場合は `/nippo-reflection` で問いかけを生成できます

-
```
