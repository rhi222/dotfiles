# 部長会報告リライトスキル

現場チームからの案件×進捗の羅列を、役員が求める「組織としての統制力」が見える報告に変換する。

## 処理フロー

1. **対象ファイル読み込み**: 指定された報告ファイル（または現在編集中の `05_Organization/Buchokai/*.md`）を Read で読み込む
2. **重点課題の読み込み**: `05_Organization/Buchokai/重点課題.md` を Read で読み込む。存在しない場合はスキップし、ステップ3の「重点課題への取り組み」セクションを省略する
3. **変換**: `system-prompt.md` のルールに従い、元データを分析・再構成する
4. **出力**: `output-format.md` のテンプレートに従い役員報告を生成する
5. **追記**: 元ファイルの末尾に `---` 区切り線を挿入し、その下にリライト結果を追記する

## 自動検知

`05_Organization/Buchokai/` 配下のmdファイルを編集中に以下のパターンを検知した場合、リライトを提案する:

- 天気マーク（☀️🌫️☔）付きのセクションが複数ある
- 🔴🟢の凡例が含まれている
- 案件名 + 進捗の箇条書きが羅列されている

## 参照ファイル

- 変換ルール: `system-prompt.md`（同ディレクトリ）
- 出力テンプレート: `output-format.md`（同ディレクトリ）
- 重点課題: `05_Organization/Buchokai/重点課題.md`（Vault内）
