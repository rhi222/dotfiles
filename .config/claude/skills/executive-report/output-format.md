# 出力テンプレート

```markdown
## 役員報告リライト案

### 全体所感

**{天気マーク} {一言サマリ（20文字以内）}**

### 重点課題への取り組み

**{課題名}**

- {報告データから紐付けた進捗}
- {必要に応じて複数行}

### リスクと対策

**{N}. {テーマ名}**

- 状況: {何が起きているか}
- 対策: {何をしているか}
- 見通し: {いつ・どうなる見込みか}

### 共有事項

- {役員が知っておくべき情報}

### 補足: 各ユニット個別進捗

上記の案件単位の記載を参照
```

## 注意事項

- テンプレート内の `{...}` はプレースホルダ。実際の内容で置換する
- 重点課題セクションは `重点課題.md` が存在する場合のみ出力
- リスクと対策は2〜3個。見通しが不明な場合でも「見通し:」行は残し、現状の判断を記載する
- 共有事項がない場合はセクション自体を省略可
