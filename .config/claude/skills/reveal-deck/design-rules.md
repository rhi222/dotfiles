# デザインの約束事

雛形（`assets/template.html`）のCSSはこの約束事で作ってある。新しい部品を足すときもこれに従う。

## 色

| 用途                         | 値                                                                    |
| ---------------------------- | --------------------------------------------------------------------- |
| 見出し・タイトル             | `--brand #3e64a0`                                                     |
| 表の見出し行、強い文字       | `--navy #2b4a7a`                                                      |
| 本文                         | `--ink #222a33`／補足 `--sub #5f6b7a`                                 |
| 注意・課題（カードの背景）   | 淡いオレンジ `#fdf4ea`、枠 `#f1d3b4`、文字 `--red #c8641a`            |
| 前進・打ち手（カードの背景） | 淡い青 `#eef4fb`、枠 `#c3d5ec`                                        |
| メインメッセージ帯           | 背景 `#e8f1fb`、左線 `#2a5ea8`（8px）、文字 `#1c2b45`、強調 `#b85a12` |

濃い青の塗りに白文字は、判定の「測り方」のような小さな箱1つまでにする。

## 辺の装飾は1スライド1パーツ

- カードの特定の辺に色線を付ける装飾（左線・上線）は、メインメッセージの帯（`.bigmsg`）だけに使う
- 目安は1スライドに1パーツ。ほかのカードは四辺同じ細い枠の、装飾なしにする
- 強調したいことは、文言・配置・背景色・大きさで示す

## 帯（`.bigmsg`）

- そのスライドでいちばん持ち帰ってほしい一文を置く。スライドの一番下
- 淡い青の背景、左に濃い青の太線、右の角を丸める。オレンジの線や濃い塗りにしない
- 強調（`.arrow`）は1か所。2行に分けるときは上下に積む（左右2列にしない）

## 組み方

- 打ち手のスライドは「いま（1行の帯）→ 打ち手（いちばん大きく。図＋箇条書き）→ 変わること（3枚のカード）」の上下3段
- 左から右へ矢印でつなぐだけのシーケンス図は避ける。流れを見せたいときは、まとめの流れ図のように列見出し（問い）を付ける
- 狭い列に文章を入れて改行だらけにしない。3列の箇条書きや2列の帯は縦に積み、1項目1行に収める
- 時系列の表は、行＝施策（レーン）、列＝時期にする。施策の並びをタイトル・本文と同じ順にそろえる
- 余白が大きく残ったら、文字を大きくして埋める。はみ出したら小さくする（下限は10.5px）

## 文言

- タイトルは句読点を少なく。「〜：〜」の形で、1行に収める
- 期日は1枚（マイルストーンのスライド）にだけ、「目安」として書く。ほかのスライドで期日を繰り返さない
- 否定で言わない（「〜をやめない」より「〜に引き続き取り組む」）
- 比喩やキメ語（本丸、窓口を出す など）は使わない。humanize スキルの基準に合わせる
- 数字・事例は出典を確かめてから載せる。比べたデータがなければ「主因」と言わず「目立った」に狭める
