# 部品カタログ

クラスはすべて `.reveal` の下で効く。使い方の実例は `assets/template.html` のサンプル6枚にある。

| 部品             | クラス                                                               | 使いどころ                                             |
| ---------------- | -------------------------------------------------------------------- | ------------------------------------------------------ |
| スライド番号     | `span.num`                                                           | 右上。`n / N`                                          |
| 小見出し         | `p.kicker`（`.gray`）                                                | 問いの番号や会議名。左に短い線が付く                   |
| タイトル         | `h2.title`（長いときは `.fit`）                                      | 1行                                                    |
| リード           | `p.lead`                                                             | 背景を1〜2文。`<b>` で一語だけ強調                     |
| 本文の器         | `div.content`                                                        | 上に区切り線。中は縦に並ぶ                             |
| カード           | `div.panel`（`.good` 淡い青／`.bad` 淡いオレンジ）                   | 装飾なし。見出しは `h3`                                |
| 表               | `table.t`（`.review` 振り返り／`.gap` 差分／`.plan` マイルストーン） | 見出し行は濃い青。奇数行に薄い地                       |
| 判定バッジ       | `span.badge.ok／.risk／.part`                                        | 表の判定列（`td.judge`）                               |
| 注力点の行       | `div.focus` ＞ `.focus-h`＋`.focus-c`（`.tag` 付き）                 | 振り返りの下で「注力するのは2つ」を見せる              |
| 問いの道しるべ   | `div.agenda` ＞ `.step`（今の問いは `.on`）                          | 冒頭で問いの順を示す                                   |
| 前提パネル       | `div.panel.dir`                                                      | 「示された方向」など。縦の箇条書き                     |
| 差分＋?の箱      | `div.gaprow` ＞ `table.t.gap`＋`.arr`＋`div.goalbox`                 | 残っているもの → 決めること                            |
| いまの帯         | `div.panel.bad.now`（`p > b` がラベル）                              | 打ち手スライドの1段目                                  |
| 打ち手の大枠     | `div.panel.good.hero`（中に図と `ul.tight`）                         | 打ち手スライドの2段目                                  |
| 3枚カード        | `div.cols3` ＞ `.panel`                                              | 変わること・決められること                             |
| 2列              | `div.cols2`                                                          | 先行指標／遅行指標など                                 |
| 進め方の分岐     | `div.route` ＞ `.way.past／.next`（`.when` ラベル）                  | 上期→下期など                                          |
| マイルストーン   | `div.planrow` ＞ `table.t.plan`＋`.goalbox.reached`                  | 行＝施策、列＝時期。上に `p.sublabel` で「時期は目安」 |
| その先の一行     | `p.next`                                                             | 表の下の補足                                           |
| 判定の鎖         | `div.chain4` ＞ `.ch`（最後だけ `.hl`）＋`.arr`                      | イシュー→目指す状態→確かめたいこと→測り方              |
| 根拠の注記       | `div.evidence`                                                       | 会議での発言など出典つきの一文                         |
| 流れ図（まとめ） | `display:grid` の7列（3本の矢印列を含む）                            | 問い①〜④を列見出しにして、課題→施策→進め方→判定        |
| メインメッセージ | `div.bigmsg`（強調 `span.arrow`）                                    | 1スライド1つ。一番下                                   |
| 小ラベル         | `span.tag`／`p.sublabel`                                             | 「課題Bへの答え」「表の見出し」など                    |
