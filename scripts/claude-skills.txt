#   <OWNER/REPO> <skill-name>[@<version>]
#     Installs via `gh skill install` (remote). Needs the repo to be

#   local: <git-url> <sub-path> <skill-name>
#     Falls back to git clone + `gh skill install --from-local` for repos
#     that are not yet indexed. <skill-name> is the SKILL.md `name:` value,
#     used for installed-directory dedup.
